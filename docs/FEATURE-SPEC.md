## 〇、产品的一句话定义

> **在跨镜头保持角色一致性的前提下，端到端自主产出 60-90 秒可交付短剧成片。**

这句话就是答辩开场白，也是全队的验收标准。

**"角色一致性"是那个「特定能力」** —— 它把"AI 生成视频"这种泛能力，收窄成了**别人做不到、我们能测出来做得到**的能力。

## 一、判据：什么算「智能体」，什么算「套壳」

开发时反复拿这张表自检。评委实际是在分三档：

| 档位 | 形态 | 特征 | 得分 |
|---|---|---|---|
| ① 套壳 | 调模型 + 写提示词 + 做个界面 | 输入→模型→输出，一问一答 | 低 |
| ② 工作流 | 固定流程串联多次模型调用 | 步骤是**人预先定死**的 | 中 |
| ③ 智能体 | 自主决策 + 工具调用 + 自我反思 | 步骤是**它自己根据情况决定的** | 高 |

**②→③ 的唯一分界线：是否有自主决策。**

一个真智能体至少要具备：

- **工具调用** —— 能真的操作系统（查库、建工单、发消息），而不只是生成文字
- **规划** —— 把目标自主拆成步骤
- **记忆/状态** —— 跨轮次、跨任务保持上下文
- **反思闭环** —— 检查自己的产出，不合格就重做
- **边界意识** —— 知道什么情况该转人工

## 二、智能体内核（决策层）

> **这五个组件是"智能体"三个字的落点。缺了它们，下面所有业务功能都只是工作流。**

| 组件 | 功能 | 为什么必须有 |
|---|---|---|
| **任务规划器** | 把"做一部短剧"自主拆成可执行步骤序列，而非人写死的流程 | 证明「自主决策」 |
| **路由决策器** | 每个环节自主决定用哪个模型、哪档服务（普惠/精品） | MoMA 智能路由的落点 |
| **反思校验器** ★ | 检查自己的产出（尤其角色一致性），不合格则**自动重做** | **最能证明是智能体的一环** |
| **状态管理器** | 统一维护剧情状态机 + 角色档案 + 素材库的上下文 | MoMA 上下文管理的落点 |
| **人工闸门** | 关键节点暂停等确认，支持驳回与回退 | 行业现实（全自动必翻车） |

## 三、必修功能：七大工位

> 七个串起来是一条完整产线。**任何一个缺失，闭环就断。**

### ① 设定中心

- **角色档案管理（Character Bible）** —— 本项目的**核心资产**
  - 结构化字段：年龄 / 脸型 / 发型 / 发色 / 瞳色 / 体型、标志性服饰、语气、口头禅
  - 每个角色绑定一张**定妆参考图**（锁定）
  - 支持人工编辑、锁定、解锁
- **全局风格设定**：画风、色调、时代背景
- **大纲生成**：题材 + 人设 → 故事大纲 + 分集梗概

### ② 剧本引擎 ★ 上下文管理主战场

- **分集剧本生成**：按大纲出对白剧本
- **剧情状态机**（关键功能）
  - 结构化追踪：人物关系、谁在第 N 集知道了什么、伏笔清单、时间线
  - 每集生成后**自动增量更新**
  - 生成第 N 集时只注入「前情摘要 + 当前状态」，**不注入全部剧本**
  - 效果：上下文从 O(N) 降到 O(1)
- **剧本编辑与版本管理**

### ③ 分镜工坊

- **剧本 → 分镜表**：镜号、景别、画面描述、对白、时长、出场角色
- **角色描述自动注入**：画面描述里的角色从档案**模板化拼装**，禁止模型自由发挥
- **分镜表可视化编辑**

### ④ 视觉资产库

- **角色定妆图生成**：文生图 → 人工确认 → **锁定为参考图**
- **场景 / 道具概念图生成**
- **素材库**：分类存储、跨镜头复用、版本管理

### ⑤ 生成产线 ★ 智能路由主战场

- **草稿预览生成**（**成本优先**路由）：低分辨率、少帧数、便宜快速模型 → 只为确认构图与节奏
- **人工确认 / 驳回**：这一步必须有
- **正片生成**（**效果优先**路由）：强模型 + 参考图锚定 + 上下文注入

### ⑥ 一致性引擎 ★★ 核心亮点

- **一致性反查闭环**：生成后用多模态模型反向提问"画面中人物是否为【角色A】本人" → **不一致自动重生成** → 超过 N 次转人工
- **一致性分数计算**：face embedding 余弦相似度，逐镜头打分
- **低分镜头自动标记** → 进入重做队列

### ⑦ 后期与合规

- **配音生成**：按角色绑定音色（TTS）
- **字幕生成**
- **自动剪辑合成**：分镜片段 → 成片
- **内容安全审核**：内容安全模型过审
- **不通过 → 自动生成重做工单 → 回退重生成**

## 四、加分功能：拉开名次的部分

> 必修做完是"完整作品"，这四项做完是"高名次作品"。

| 功能 | 内容 | 价值 |
|---|---|---|
| **成本与产能看板** | 每集成片 Token 成本、路由分布（多少走便宜/强模型）、缓存命中率、人工 vs 流水线产能对比 | **答辩时最有说服力的一屏** |
| **批量任务编排** | 多集并行队列、任务状态机、失败重试、**模型故障自动切换** | 证明"产线"而非"工具" |
| **分镜级重生成** | 单个镜头改提示词 / 换模型 / 重生成，不动其他镜头 | 真实制作团队刚需 |
| **出海适配** | 多语言配音 / 字幕（多语言模型） | 加分项，出海是风口 |

## 五、明确不做（划范围比加功能更重要）

| 不做 | 原因 |
|---|---|
| ❌ 古装 / 战争 / 特效 / 复杂动作 | 生成质量不可控，必翻车 |
| ❌ 多人打斗、需精确文字渲染的镜头 | 当前模型能力边界 |
| ❌ 全自动无人值守 | 行业现实：必须有确认点 |
| ❌ 60-100 集全量生产 | 只做 **1 集完整 + 3-5 集片段**证明架构 |
| ❌ 自己训练 / 微调模型 | 不属于本赛道的"模型应用" |

## 七、最小可信闭环（时间紧就只做这条）

> 如果只有 4-6 周，砍到只剩一条主线，但**必须首尾贯通**。

```
题材输入
  → 角色档案 + 定妆图          ①④
  → 分集剧本 + 状态机          ②
  → 分镜拆解                   ③
  → 草稿生成（成本优先）        ⑤
  → 正片生成（效果优先）+ 一致性反查重做   ⑤⑥
  → 配音 + 合成                ⑦
  → 成片
```

**这条线跑通 = 你是完整作品。**

其余全部功能的边际收益，都远低于「**角色一致性反查闭环**」这一个功能的完成度。

## 八、验收标准

| 维度 | 指标 | 目标 |
|---|---|---|
| 交付完整性 | 成片 | 1 集 60-90 秒完整 + 3-5 集片段 |
| **一致性** | face embedding 余弦相似度 | 逐镜头可量化，有分数分布 |
| 剧情连贯 | 人工盲评 / 状态机正确率 | 可统计 |
| 成本 | 每集成片 Token 成本 | 三组对照实验数据 |
| 产能 | 单集耗时 | 人工 vs 流水线对比 |
| 智能体性 | 自主决策点数量 | ≥3 处（规划/路由/反思） |
