# 「爆量工场 BoostForge」执行方案

> 短剧投流素材工厂 —— 从一集成片出发，批量产出高转化素材，并依据投放数据回流持续进化
> 面向：第五届「移动云杯」智算应用创新大赛 · **模型应用赛**（AI短剧场景） ｜ 基于 MoMA 平台 ｜ 团队 4 人

---

## 一、结论先行

**选题：短剧投流素材工厂（含 AI 重生成钩子镜头）**

不做"再造一部短剧"，而是做**让已有短剧赚到更多钱的那一层**。

### 一句话对比

| | 工业化流水线（A） | **投流素材工厂（B）** |
|---|---|---|
| 核心难题 | **生成** —— 不可控，模型做不到就是做不到 | **择优** —— 可控，"好不好"有客观数据说了算 |
| 押注 | 行业未解决的难题（角色一致性） | 已解决的问题（用数据挑素材） |

> **B 的风险比 A 低一个量级，因为它的成败标准是客观的：CTR 会告诉你哪个素材好。**

### 为什么这个痛点是真的

短剧行业最大的成本**不是制作，是投流**——买量成本占收入 **70-80%**。

- 投流团队每日需产出 **几十到上百条**素材做 A/B 测试
- 素材**衰减极快**，同一条跑 3-7 天就疲劳，必须持续产出新的
- 人工剪辑产能是硬瓶颈

**这是一个花钱如流水、且可以量化 ROI 的环节。**

## 二、产品定义

### 产品定位

**「爆量工场 BoostForge」** —— 面向短剧投流团队的 **AI 素材工厂与投放策略优化智能体**。

> "爆量"是投流行业黑话，指素材跑出流量。

### 特定能力（答辩开场白）

> **从一集已有成片出发，批量产出可投放的投流素材，并依据投放数据回流，让每轮素材的转化率高于上一轮。**

注意最后半句 —— **"每轮比上一轮好"才是"特定能力"，"批量产出素材"只是功能。**

### 输入输出

| | 内容 |
|---|---|
| 输入 | 一集成片 + 投放目标（平台/人群/预算） |
| 输出 | 素材包（含优先级排序）+ 投放建议 + 效果复盘报告 |

## 三、技术架构：七工位流水线

```
【输入】一集成片 + 投放目标

① 高光片段识别
   视频理解模型 → 定位冲突 / 反转 / 情绪爆点 / 金句
   输出：高光候选列表（时间码 + 类型标签 + 强度分）
        ↓
② 钩子设计 ★核心
   短剧投流决定成败的是前 3 秒
   文本模型 → 为每个片段设计 N 个钩子方案
   钩子类型库：悬念型 / 冲突型 / 反转型 / 情感型 / 利益型
        ↓
③ 素材变体生成
   · 切片（不同起止点、不同时长 15s/30s/60s）
   · 钩子前置（把最精彩 3 秒剪到开头）
   · ★ AI 重生成钩子镜头（文生视频，见下）
   · 封面图（文生图/图生图 × N 版本）
   · 配音变体（不同音色 TTS）
   · 字幕 / 贴纸（模板化）
        ↓
④ 质检与合规
   内容安全模型 → 各平台规则不同，需分平台校验
   画面质量检测（模糊/黑边/音画不同步）
        ↓
⑤ 素材打分与排序 ★
   预测 CTR 模型 → 优先级排序 + 推荐投放组合
        ↓
⑥ 投放与数据回流
   小流量测试 → CTR / 完播率 / 转化 / ROI 回流
        ↓
⑦ ★★ 策略进化器 ★★
   分析哪类钩子 / 封面 / 时长 / 音色效果好
   调整下批生成策略
        ↓
   回到 ②  （闭环）
```

## 四、★ 为什么这是「智能体」而非工作流

这是评委最会追问的点。**自主决策点必须清晰可见：**

| 内核组件 | 自主决策内容 | 为什么不是工作流 |
|---|---|---|
| **任务规划器** | 自主决定"这批生成多少条、什么类型组合"（依据素材衰减速度与投放缺口） | 数量与配比是**算出来的**，不是写死的 |
| **高光选择器** | 自主判断哪个片段有爆发潜力 | 需要判断，非规则匹配 |
| **路由决策器** | 低优先级素材走普惠档、高优先级走精品档；质检不过自动重做 | 按素材价值动态选模型 |
| **★★ 策略进化器** | **根据回流数据自主调整生成策略** | **会改变自己的行为** ← 最强自主性 |
| **反思校验器** | 预测 CTR 过低 / 质检不通过 → 自动重做 | 检查产出并重做 |
| **人工闸门** | 正式投放前人工确认 | 行业现实 |

> **一句话**：工作流不会改主意，**只有"会根据结果改变自己策略"的系统才是智能体。** 策略进化器就是那个东西。

## 五、★ 核心亮点：数据回流闭环

这是全方案最值钱、也最需要正面处理的部分。

### 闭环逻辑

```
生成素材 → 投放 → 拿到 CTR → 分析哪类有效 → 调整策略 → 生成更好的素材
```

### ⚠️ 硬伤与解法（必须在方案里正面处理）

**问题：比赛没有投流预算，拿不到真实投放数据。**

**三层数据策略：**

| 层次 | 做法 | 定位 |
|---|---|---|
| **① 历史数据集离线回放** | 收集公开短剧投放素材+效果数据；Agent 按时间顺序"回放"，接收数据并迭代 | **主力方案** |
| **② 小额真实投放** | 抖音千川/巨量，几百元预算做真实 A/B 测试，拿真实 CTR | **增强说服力** |
| **③ CTR 预测模拟器** | 训练一个 CTR 预测模型充当"模拟投放环境"，Agent 在其中进化 | **兜底** |

> **学术上这叫「离线评估」（offline evaluation of online learning）**，是成熟做法。
> **关键：必须在报告里如实说明数据来源，藏不住，且诚实说明反而是加分项。**

## 七、AI 重生成钩子镜头（折中模块）

**为什么要加这个模块：**

| 目的 | 说明 |
|---|---|
| 补足 Token 消耗 | 赛道按"高 Token 消耗场景"筛选，纯理解+剪辑可能不达标 |
| 增加变体多样性 | 同一个开头可以有几十个视觉版本 |
| 提升演示效果 | 能展示"同一钩子的不同视觉呈现"对比 |
| **风险极低** | **只生成 3 秒片段，且不要求跨镜头一致性** |

> 这是 A 方案的视频生成能力，但**剥离了它的致命风险** —— 不做连续剧，只做 3 秒钩子。

## 八、评测体系

| 维度 | 指标 | 方法 |
|---|---|---|
| 产能 | 每小时产出素材条数 | vs 人工剪辑 |
| 质量 | 预测 CTR 与实际 CTR 的误差 | 回归指标 |
| **★ 学习效果** | **迭代 N 轮后实际 CTR 的提升幅度** | **核心指标** |
| 成本 | 每千条素材的 Token 成本 vs 人工成本 | 成本对比 |
| 合规 | 素材过审率 | 平台规则校验 |

### ★ 三组对照实验（最有说服力的部分）

| 方案 | 成本 | 素材 CTR |
|---|---|---|
| 纯人工剪辑 | 基准（高） | 基准 |
| Agent 只生成（**无学习**） | 低 | 持平或略低 |
| **Agent 带回流学习** | **低** | **显著提升** |

> **第三行就是全案的价值证明**：成本大幅低于人工，且效果**还更好**——因为机器能同时测试几百个变体，人类做不到。

## 九、团队分工（4 人）

| 角色 | 职责 | 关键交付 |
|---|---|---|
| **P1 · 队长 / 产品 + 投流策略** | 投流业务理解、钩子类型库设计、投放策略、产品设计报告、答辩主讲、进度管理、组委会问询 | 策略库、设计报告、答辩 PPT |
| **P2 · 后端 / 架构** | MoMA 网关、七工位编排、路由决策器、批量任务队列、**数据回流管道** | 编排层、数据管道 |
| **P3 · 算法 / 策略进化** | **预测 CTR 模型、策略进化器**、高光识别、评测体系 | 进化器、评测报告 |
| **P4 · 前端 / 全栈** | 素材墙、投放看板、效果曲线、素材管理、AI Store 材料 | 前端产品、上架材料 |

> **⚠️ 注意 P1 的技能要求变了**：不再是"编剧"，而是**懂投流业务**。
> 投流是个专业领域（钩子设计、人群定向、素材衰减规律），**这个领域的知识是方案的护城河**。找不到懂投流的人，方案的深度会差一截。

### 关键路径

```
P3 高光识别 + CTR预测 + 策略进化 ──┐
   (技术命门，最先启动)            │
                                  ├──→ 闭环验证 → 对照实验 → 材料
P2 编排 + 数据回流管道 ───────────┤
                                  │
P4 前端素材墙 + 看板 ─────────────┘

P1 投流策略 + 报告 + 答辩 ── 全程并行
```

### 三条铁律

1. **P3 最先动工**（CTR 预测与策略进化是技术命门）
2. **P2 与 P4 先冻结接口**再各自开工
3. **P1 不参与编码**，专注投流业务与答辩

## 十一、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **拿不到历史投放数据** | **极高** —— 闭环立不住 | Phase 0 最优先解决；退路：小额真实投放 / CTR 模拟器 |
| **CTR 预测不准** | 高 | 特征工程简化；接受"相对排序准"而非"绝对值准" |
| **Token 消耗不够"高"** | 中 | AI 重生成钩子镜头模块补足 |
| **演示不如造剧直观** | 中 | 素材墙 + CTR 提升曲线 + **前后对比**（第一轮 vs 第N轮） |
| **P1 不懂投流业务** | 中 | 尽早补课或找懂的人；这是方案深度所在 |
| **合规风险** | 中 | 素材必须过平台规则校验；不生成虚假宣传内容 |

## 十二、立即要做的三件事

1. **找历史投放数据集** —— 闭环的生命线，Phase 0 最高优先级
2. **确认 Token 配额覆盖视频模型** —— 唯一可能推翻方案的硬约束
3. **定 P3 人选** —— CTR 预测 + 策略进化是技术命门
