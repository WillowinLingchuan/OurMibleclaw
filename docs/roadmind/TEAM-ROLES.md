# RoadMind · 11 天冲刺

> **目标：11 天后能演三个场景。做不完的东西一律砍掉，不商量。**
> 倒推起点：2026-09-26（周六）｜ 终点：2026-10-06（周二）

---

## 一、11 天后要能演什么（这就是验收标准）

**只演三件事。这三件演不出来，等于没做。**

| # | 演什么 | 说明 |
|---|---|---|
| **1** | 输入一份案卷 → 出一张**要件对照表** | 每条要件标「具备 / 待确认 / 缺失」，每条都指向证据 |
| **2** | 系统**敢说「这一项我没有证据」** | 这一条比第 1 条更能证明它不越界 |
| **3** | **同一案件重做一遍，结果变了** | 喂它一批已结案件 → 要件库被改写 → 重跑同一案件 → 多问一个问题 |

第 3 条是命门。**它演不出来，这就不是智能体，只是一个读材料的大模型。**

## 二、砍掉了什么（10 周计划 → 11 天）

> **砍不是妥协，是保命。** 11 天做 10 周的事，只能保命门。

| 项 | 10 周计划 | **11 天** |
|---|---|---|
| 文书数量 | ≥50 份 | **30 份**（拿不到就 20 份） |
| 要件库 | ≥30 条条款 | **12 条** |
| A3 对抗质证 | 独立 Agent + 对抗回边 | **降为一次「自查」调用**，不做回边 |
| 追问规划器 | 集合覆盖求解 | **砍** |
| 视频识别 | 三步完整（抽帧+检测+跟踪） | **砍**（D9 有余力再加，见第六节） |
| 评测指标 | 8 个指标 + 三组对照实验 | **只留 1 个**：覆盖完整度（第 1 轮 vs 第 N 轮） |
| 稳定性基线 | 跑 10 次算 Jaccard ≥ 0.8 | **跑 3 次看一致性**，不进正式文档 |
| 工具层 | 4 个 Function-call | **只做法条检索** |
| 护栏 | 完整校验器 | **只做条款 ID 白名单**这一条 |
| 界面 | 工作台 + 前后对比 + 思考链 + 视频查看器 | **工作台 + 前后对比**（思考链降为文字日志） |
| 答辩/上架 | PPT + 彩排 + 材料 | **只录一段演示视频** |

**没砍的只有一样：A4 复盘。** 它是全案唯一「会改主意」的地方，砍了它整个方向就没有存在理由。

## 五、三条铁律

1. **每天下班前必须有能跑的东西。** 不许"今天写完了明天测" —— 明天自会有人告诉你今天还没写完。
2. **D3 的泄漏扫描，D7 的端到端，D8 的 A4 跑通** —— 这三个点不过，就地停下来补，不许往后带。
3. **演示案件绝不进 A4 的复盘集。** 这一条写在代码里断言：`assert demo_case_id not in a4_review_case_ids`。**被问倒就全完了。**
